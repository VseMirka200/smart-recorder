# 🎉 Smart Recorder v1.0.0

The first stable Smart Recorder release — an AutoHotkey v2 application for recording and replaying mouse and keyboard actions, automating repetitive tasks, and running test scenarios.

> **Русский:** [Открыть русские заметки релиза](../../releases/v1.0.0.md).

## ✨ Highlights

- mouse and keyboard action recording;
- playback with configurable speed;
- configurable repetition count;
- random cooldown between repetitions;
- automatic recording save/load;
- test-profile generation;
- OCR assistant;
- F3/F4 workflows;
- action journal and status panel;
- custom application icon;
- Windows EXE release assets.

## 📦 Assets

- **SmartRecorder-v1.0.0.exe** — ready-to-run application;
- **SmartRecorder-v1.0.0-portable.zip** — portable package;
- **SHA256SUMS.txt** — SHA-256 checksums for release files.

## ⌨️ Main hotkeys

| Key | Action |
|---|---|
| `F1` | action journal |
| `F2` | profile-age action |
| `F3` | sex selection |
| `F4` | answer / screenshot workflow |
| `F5` | new profile |
| `F6` | enable / disable OCR |
| `F7` | OCR action |
| `F8` | start / stop recording |
| `F9` | playback |
| `F10` | stop playback |
| `F11` | status panel |
| `F12` | settings |
| `Esc` | exit |

## ⚠️ Important

The application may create action recordings and screenshots. Review files for personal or confidential information before publishing them.

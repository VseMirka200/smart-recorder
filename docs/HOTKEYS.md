# Горячие клавиши

Ниже приведены горячие клавиши, зарегистрированные в текущем `SmartRecorder.ahk`.

| Клавиша | Действие |
|---|---|
| `F1` | показать или скрыть журнал действий |
| `F2` | использовать текущий возраст тестового профиля |
| `F3` | выполнить сценарий выбора пола |
| `F4` | выполнить сценарий ответа/снимка, предусмотренный текущей записью |
| `F5` | создать новый тестовый профиль |
| `F6` | включить или выключить OCR-помощник |
| `F7` | выполнить действие OCR-помощника / ввести предложенный ответ |
| `F8` | начать или завершить запись действий |
| `F9` | запустить воспроизведение текущей записи |
| `F10` | остановить воспроизведение |
| `F11` | показать или скрыть панель состояния |
| `F12` | показать или скрыть окно настроек |
| `Esc` | завершить Smart Recorder |

## F8 — запись

При запуске записи программа начинает фиксировать поддерживаемые события мыши и клавиатуры. Повторное нажатие завершает запись и сохраняет её в рабочий файл.

Во время изменения собственного GUI программа может временно игнорировать часть событий, чтобы служебные действия не попадали в запись.

## F9 — воспроизведение

Перед запуском применяются параметры окна настроек:

- количество повторов;
- скорость;
- диапазон кулдауна;
- параметры тестового профиля.

Если включено создание нового профиля перед каждым повтором, возраст и пол обновляются в соответствии с выбранными настройками.

## F10 — остановка

F10 предназначена для немедленной остановки текущего playback. После остановки программа должна вернуть внутреннее состояние в безопасный режим и освободить клавиши, которые могли удерживаться воспроизведением.

## F2/F3/F5 — профиль

- `F2` связан с текущим возрастом профиля;
- `F3` связан с выбором пола;
- `F5` полностью генерирует новый профиль.

Точное поведение зависит от текущего состояния формы и настроек профиля.

## F6/F7 — OCR

OCR является дополнительной возможностью. Если зависимость OCR недоступна, программа должна сообщить об этом в интерфейсе или журнале, не нарушая обычную запись и воспроизведение.

## F4

F4 является специальным сценарием приложения. При изменении его поведения обязательно обновляйте этот файл и README, потому что F4 менялся в ходе разработки чаще обычных горячих клавиш.

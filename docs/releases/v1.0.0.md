# 🎉 Умный рекордер v1.0.0

Первый стабильный релиз **Умного рекордера** — программы на AutoHotkey v2 для записи и воспроизведения действий мыши и клавиатуры, автоматизации повторяющихся действий и тестовых сценариев.

## ✨ Основные возможности

- запись действий мыши и клавиатуры;
- воспроизведение с настраиваемой скоростью;
- настройка количества повторов;
- случайный кулдаун между повторами;
- автоматическое сохранение и загрузка записей;
- генерация тестового профиля;
- OCR-помощник;
- сценарии F3/F4;
- журнал действий и панель состояния;
- собственная иконка приложения;
- сборка Windows EXE.

## 📦 Assets

- **SmartRecorder-v1.0.0.exe** — готовая программа, AutoHotkey устанавливать не требуется;
- **SmartRecorder-v1.0.0-portable.zip** — портативный комплект;
- **SHA256SUMS.txt** — контрольные SHA-256 суммы файлов релиза.

## ⌨️ Основные горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | журнал действий |
| `F2` | действие с возрастом профиля |
| `F3` | выбор пола |
| `F4` | сценарий ответа / снимка |
| `F5` | новый профиль |
| `F6` | включить / выключить OCR |
| `F7` | OCR-действие |
| `F8` | начать / остановить запись |
| `F9` | воспроизведение |
| `F10` | остановить воспроизведение |
| `F11` | панель состояния |
| `F12` | настройки |
| `Esc` | выход |

## ⚠️ Важно

Программа может создавать записи действий и снимки экрана. Перед публикацией файлов проверяйте их на наличие персональных или конфиденциальных данных.

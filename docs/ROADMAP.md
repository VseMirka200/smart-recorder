# План развития

Этот файл описывает возможные направления развития Smart Recorder. Пункты не являются обещанием сроков и могут меняться по мере развития проекта.

## Ближайшие задачи

- дальнейшее упрощение и выравнивание GUI;
- вынесение повторяющихся GUI-координат в более удобную систему компоновки;
- улучшение диагностики ошибок записи и воспроизведения;
- более явное отображение текущего файла записи;
- улучшение обработки ошибок OCR;
- проверка работы на разных масштабах интерфейса Windows;
- подготовка стабильной схемы версий и релизов.

## Надёжность

- уменьшить зависимость от фиксированных задержек;
- добавить дополнительные проверки состояния перед кликами и вводом;
- улучшить восстановление после остановки воспроизведения;
- убедиться, что нажатые во время playback клавиши всегда освобождаются;
- улучшить обработку многомониторных конфигураций.

## Запись и воспроизведение

- сделать формат записи более явно версионируемым;
- добавить проверку совместимости старых `.srm`;
- улучшить сообщения об ошибках повреждённых записей;
- добавить безопасный предварительный просмотр параметров записи перед запуском.

## Интерфейс

- привести все группы настроек к одной сетке отступов;
- улучшить масштабирование DPI;
- добавить более компактные статусы без перегрузки окна;
- отделить основные действия от редко используемых настроек.

## Разработка

- добавить автоматическую проверку синтаксиса и сборки в GitHub Actions;
- добавить минимальные автоматизированные тесты для функций преобразования времени и данных записи;
- формализовать правила версионирования;
- публиковать собранный EXE как артефакт релиза после появления стабильного процесса выпуска.

## Документация

- поддерживать README и список горячих клавиш в соответствии с кодом;
- дополнять FAQ реальными частыми проблемами;
- фиксировать заметные изменения в [`CHANGELOG.md`](../CHANGELOG.md).

## О программе

**Умный рекордер** — настольная утилита для записи действий мыши и клавиатуры и их последующего воспроизведения с настраиваемой скоростью, количеством повторов и интервалами между ними.

Программа содержит генератор тестового профиля, OCR-помощник, журнал действий, отдельную панель состояния и автоматическое сохранение рабочей записи.

Актуальная стабильная версия — **1.0.0**. Готовый `SmartRecorder.exe` доступен по кнопке **«СКАЧАТЬ»** выше.

## Возможности

- запись действий мыши и клавиатуры;
- воспроизведение записей с настраиваемой скоростью;
- заданное количество полных повторов;
- случайный кулдаун между повторами;
- автоматическое сохранение и загрузка рабочей записи;
- загрузка другой записи через интерфейс;
- генерация тестового профиля с возрастом и полом;
- создание нового случайного профиля перед каждым повтором;
- OCR-помощник для сценариев с распознаванием элементов формы;
- специальные сценарии для выбора пола и ответа/снимка области;
- журнал действий;
- отдельная панель состояния;
- сборка в самостоятельный Windows EXE.

## Быстрый старт из исходного кода

1. Установите AutoHotkey v2.
2. Скачайте или клонируйте репозиторий.
3. При необходимости запустите `Install_OCR.bat`.
4. Запустите `SmartRecorder.ahk`.

OCR-зависимость `OCR.ahk` при необходимости восстанавливается автоматически и не обязана храниться в чистом клоне репозитория.

## Основные горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | показать или скрыть журнал действий |
| `F2` | действие с текущим возрастом профиля |
| `F3` | сценарий выбора пола |
| `F4` | специальный сценарий ответа/снимка |
| `F5` | создать новый тестовый профиль |
| `F6` | включить или выключить OCR |
| `F7` | действие OCR-помощника |
| `F8` | начать или остановить запись |
| `F9` | запустить воспроизведение |
| `F10` | остановить воспроизведение |
| `F11` | показать или скрыть панель состояния |
| `F12` | показать или скрыть настройки |
| `Esc` | выход |

Полное описание: [`docs/HOTKEYS.md`](docs/HOTKEYS.md).

## Настройки

В окне программы доступны:

- количество повторов;
- скорость воспроизведения;
- диапазон кулдауна;
- диапазон возраста;
- режим пола;
- создание нового профиля перед каждым повтором;
- включение OCR;
- загрузка другой записи.

## Форматы времени

Поля кулдауна поддерживают удобные текстовые варианты:

```text
3м
3м30с
90с
00:03:30
```

```text

```

Эти каталоги могут содержать пользовательский ввод или содержимое экрана и не должны публиковаться без предварительной проверки.
